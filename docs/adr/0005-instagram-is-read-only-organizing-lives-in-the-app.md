# Instagram is a read-only source; organizing lives only in the app

Sync only flows Instagram → app, and only for what Instagram owns: whether a post is saved, its caption, its owner. Everything the user organizes — Collection membership, Tags, Title, Post Note, Collection Notes — belongs to the app and is never overwritten by Sync. Nothing is ever written back to Instagram (no API allows it).

Concretely, a Post already in the app is never moved by Sync, even if its Instagram Collection changes. Unsaving on Instagram doesn't delete the Post; it gets the "No longer saved" marker. Deleting in the app is remembered (Deleted Post, ADR-0012) so Sync never resurrects it. The one narrow exception to "never moved" is first-sighting placement of a Post still in To sort (ADR-0011). Caption changes update Description only while the user hasn't hand-edited it, which requires a persisted "Description was hand-edited" flag alongside the Title one (carried over from Socials Organizer ADR-0003 for the same reason: an in-memory flag would silently clobber edits after a restart).
